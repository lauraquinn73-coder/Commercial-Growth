ACCESSIBILITY

Accessibility statement.

Last updated: 11 October 2026. Commercial Growth aims to make commercialgrowth.ie accessible and usable on desktop, mobile and assistive technologies.

Accessibility approach

The website has been designed with WCAG 2.2 AA principles in mind, including semantic headings, a skip link, labelled controls, visible keyboard focus, keyboard access to Growth Check steps, dialog focus management, responsive layouts and reduced-motion support. This is not a statement that the entire website has passed an independent accessibility audit or is certified as conforming with WCAG 2.2 AA. New consent controls, security widgets and sharing forms need practical keyboard, screen-reader, zoom and mobile testing before release.

Known limitations

Some third-party services, including Cloudflare challenge widgets, Tally and email providers, control their own interfaces. Automated homepage scanning can be limited by remote websites. The experience should be tested with screen readers, zoomed interfaces, mobile browsers and keyboard-only navigation before each material release.

The impact of the optional direct submission and scan-sharing experiences has not yet been verified on VoiceOver, NVDA or TalkBack. Alternate access to the information and an enquiry by email remain available if an interactive feature cannot be used.

Request help

If a feature is difficult to use or you need an alternative format, email lauraqbusiness@gmail.com and describe what you were trying to do. We will review the issue and provide a practical alternative where possible.

Optional privacy withdrawal controls use an explicitly labelled code field, keyboard-operable submit button and a live status announcement. These controls are subject to manual accessibility testing before being enabled publicly.
