# Commercial Growth.ie

Static responsive website for Commercial Growth.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js` and this README to the repository root.
3. In GitHub: **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide a free `github.io` address.

## Custom domain
If you own `commercialgrowth.ie`, add it under **Settings → Pages → Custom domain** and then point the domain DNS records to GitHub Pages using the records GitHub provides.

## Before launch
The site currently includes `hello@commercialgrowth.ie`. Replace it in `index.html` if that email address does not exist yet.
