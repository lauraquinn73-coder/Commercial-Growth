# Commercial Growth launch site

Static site prepared for GitHub Pages and the custom domain `commercialgrowth.ie`.

## Included
- `index.html`
- `styles.css`
- `script.js`
- `favicon.svg`
- `robots.txt`
- `sitemap.xml`
- `CNAME`

## GitHub Pages
Upload these files to the root of the GitHub Pages repository. The included `CNAME` file tells GitHub Pages to use `commercialgrowth.ie` as the custom domain.

Do not change DNS until the domain is active with the registrar. Once active, configure the domain DNS for GitHub Pages and enable HTTPS in the GitHub Pages settings when available.
